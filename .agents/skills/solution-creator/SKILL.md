# Solution Creator
Goal: turn an unmet goal into an executable solution.

1. Normalize the desired outcome, constraints, resources, and success condition.
2. Identify the smallest mechanism that could produce the outcome.
3. Generate at least 3 materially different architectures when the problem is non-trivial.
4. Prefer creation over retrieval: existing solutions are references, not answers.
5. For blocked paths, explicitly derive substitute mechanisms, workarounds, simulations, or a reduced-scope version.
6. Select the strongest path using feasibility, speed, cost, risk, and leverage.
7. Produce concrete artifacts: design, interfaces, files, code, tests, or execution steps as appropriate.
8. Verify the created solution against the success condition and record remaining unknowns.

Completion means a new actionable solution exists, not merely a list of links or recommendations.
