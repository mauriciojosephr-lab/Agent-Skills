# Multi-Path Solver
Run a solution portfolio, not a single guess.

Produce:
- Path A: fastest viable
- Path B: safest / lowest-risk
- Path C: cheapest / lowest-resource
- Path D: highest-leverage
- Path E: unconventional or newly invented

For each: mechanism, dependencies, failure modes, cost, time, and verification method.
Then compare and either select one or combine complementary mechanisms.
If a path is blocked, keep the path as a rejected hypothesis and derive a replacement rather than silently dropping it.
