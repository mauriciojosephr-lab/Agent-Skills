# Skill Marketplace Curator

Search multiple ecosystems. Rank candidates by usefulness, evidence, maintenance, license, scope, and security. Inspect content and referenced files before import. Prefer adaptation over wholesale copying. Record source, version/commit, decision, changes, and acceptance test.
