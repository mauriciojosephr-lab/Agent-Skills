# Secretless Integration

Prefer short-lived, scoped credentials and platform identity. Never place secrets in prompts, source, logs, issues, fixtures, or skill text. Identify required credential boundaries, rotation, revocation, and failure behavior. Validate that test paths do not require production secrets.
