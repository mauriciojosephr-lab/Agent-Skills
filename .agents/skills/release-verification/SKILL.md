# Release Verification

Check the exact artifact/commit, build, tests, deployment, health endpoint, critical user path, error path, security controls, observability, and rollback. Verify production behavior separately from local behavior. Record what was actually executed and what remains unverified. A green CI run is evidence, not proof of every runtime property.
