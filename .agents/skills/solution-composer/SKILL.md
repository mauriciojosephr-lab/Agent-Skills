# Solution Composer
1. Inventory available capabilities and their inputs/outputs.
2. Find compatible compositions rather than evaluating components in isolation.
3. Design a contract between components.
4. Build the smallest end-to-end composition.
5. Validate each handoff and the final outcome.
6. If no composition works, alter one interface or add the smallest missing capability.

The purpose is emergent capability: create something that no single existing skill provides.
