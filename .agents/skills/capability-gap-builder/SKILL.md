# Capability Gap Builder
1. State the desired end state.
2. Map the current capability chain.
3. Find the first missing capability that prevents progress.
4. Decide whether it can be implemented as a skill, script, adapter, test harness, data artifact, or workflow.
5. Build the smallest useful version.
6. Add validation and a usage contract.
7. Re-run the original task through the new capability.
8. If still blocked, repeat for the next gap.

Never disguise a missing capability as a successful result.
