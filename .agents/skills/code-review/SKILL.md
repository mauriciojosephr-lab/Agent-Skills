# Code Review

Start from the diff and affected interfaces. Identify concrete defects before style preferences. Check edge cases, error paths, concurrency, data validation, auth boundaries, tests, backward compatibility, performance regressions, and operational impact. For every finding give evidence, severity, and a minimal remediation. Do not approve because the code merely looks plausible.
