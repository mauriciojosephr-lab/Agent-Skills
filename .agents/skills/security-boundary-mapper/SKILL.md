# Security Boundary Mapper

Draw logical boundaries from inputs to tools, storage, external services, and outputs. Mark authentication, authorization, trust transitions, sensitive data, and attacker-controlled fields. Test each crossing for confused deputy, injection, privilege escalation, and exfiltration paths. Return highest-risk boundaries first.
