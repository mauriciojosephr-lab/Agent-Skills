# Bug Triage

Reproduce first when possible. Separate symptom from root cause. Classify severity, scope, affected versions, exploitability, customer impact, and regression risk. Link evidence. Prefer a minimal reproducible case. Propose the smallest safe fix plus regression tests. Do not close a bug because it cannot currently be reproduced; record missing evidence and next diagnostic step.
