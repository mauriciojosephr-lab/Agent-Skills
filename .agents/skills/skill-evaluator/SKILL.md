# Skill Evaluation

Score purpose clarity, trigger precision, scope boundaries, evidence of use, deterministic outputs, safety, maintainability, dependencies, overlap, and testability. Reject skills that are vague prompt collections, duplicate stronger skills, require unjustified broad permissions, or lack a meaningful acceptance test. Prefer adaptation over importing large bundles when only a small workflow is needed.
