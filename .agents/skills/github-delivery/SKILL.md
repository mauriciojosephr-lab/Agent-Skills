# GitHub Delivery

1. Inspect repository state and existing conventions.
2. Define the smallest coherent change.
3. Work on a dedicated branch when appropriate.
4. Add or update tests with the implementation.
5. Review the diff for unrelated changes and secrets.
6. Run relevant checks and record failures honestly.
7. Open/update the PR with scope, evidence, risks, and rollback notes.
8. Treat review comments as requirements until resolved or explicitly rejected with rationale.
