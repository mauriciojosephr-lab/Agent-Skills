# Affiliate Revenue Scout

## Workflow
1. Discover programs from structured registries and official provider pages.
2. Verify eligibility, geography, approval requirements, commission type, cookie/payout terms, prohibited traffic, and payout method.
3. Prefer recurring commissions or products that naturally fit the user's actual software/services.
4. Build a compliant placement: documentation, comparison page, onboarding link, product recommendation, or tool integration.
5. Track clicks, signups, approved conversions, and paid commissions separately.
6. Never count a signup as revenue; revenue is only `paid/confirmed` when the program reports it.

## Sources to exploit
- OpenAffiliate-style machine-readable registries.
- Provider affiliate pages.
- Open-source projects whose free model is funded by affiliate links.

## Hard rules
Never fabricate an affiliate relationship. Never insert an affiliate link where the program does not permit it. Never hide material affiliate disclosures. Never store affiliate account passwords or private tokens in Git.
