# Architecture X-Ray

Infer modules, boundaries, entry points, data flows, external services, and runtime topology from code/config/tests. Distinguish observed from inferred structure. Highlight architectural hotspots, hidden coupling, dead paths, and undocumented assumptions. Produce a diagram-ready model and verification list.
