# Solution Evolver
Treat every result as version N, not the endpoint.

1. Capture what worked and failed.
2. Identify the highest-value weakness.
3. Generate multiple modifications.
4. Prefer changes that increase capability without increasing fragility.
5. Implement one or more improvements.
6. Regression-test old behavior.
7. Compare version N+1 with N using measurable criteria.
8. Keep the better version and record the lesson as reusable knowledge.

Do not optimize an unverified baseline; establish a working baseline first.
