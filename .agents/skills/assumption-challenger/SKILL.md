# Assumption Challenger
Extract the assumptions behind the proposed approach.

For each assumption:
- evidence supporting it
- evidence against it
- consequence if false
- cheap test
- replacement assumption or mechanism

Prioritize assumptions with high impact and low testing cost. Never manufacture evidence. Convert uncertain assumptions into explicit experiments or design branches.
