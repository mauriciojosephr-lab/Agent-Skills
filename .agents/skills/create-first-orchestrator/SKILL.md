# Create-First Orchestrator
Default priority: CREATE > ADAPT > COMPOSE > RETRIEVE.

1. Define the outcome and verification signal.
2. Inspect available capabilities.
3. Challenge assumptions and constraints.
4. Generate competing solution paths.
5. Build the strongest new mechanism or composition.
6. If blocked, invoke an alternative-path or capability-gap strategy.
7. Test and attack the result.
8. Fix and retest.
9. Preserve useful failed paths as hypotheses/lessons.
10. Report exactly what was created, what was verified, and what remains impossible without an external dependency.

This skill is an orchestrator, not a generic “think harder” prompt. It must produce artifacts or concrete executable next steps whenever tools permit.
