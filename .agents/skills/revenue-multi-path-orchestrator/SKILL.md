# Revenue Multi-Path Orchestrator

Given a verified opportunity, generate the smallest useful set of monetization experiments across the five Revenue Engine paths.

Prefer reuse: one research result should be able to produce multiple legitimate assets without duplicating unsupported claims.

For each path define:
- value proposition
- required capability
- provider dependency
- publication state
- measurement event
- stop condition

Never publish a route whose required provider is unavailable or whose factual claims are unverified. Prefer one primary route and up to two secondary routes initially; expand only when evidence supports it.
