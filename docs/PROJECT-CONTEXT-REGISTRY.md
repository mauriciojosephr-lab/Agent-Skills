## Status integrity
Never use a demo as proof of production. Never use CI as proof of live runtime behavior. Never use pipeline verification as proof of task completion. Never use remembered conversation claims to override current repository evidence.

## Cross-project firewall
A capability shared by two projects does not transfer ownership of their state. Resolve the owning project before modifying files, runtime configuration, deployment state, or evidence records.

## Recovery rule
If an artifact is referenced but absent from its expected project scope, classify it as a recovery candidate and investigate its owner before modifying another repository.
