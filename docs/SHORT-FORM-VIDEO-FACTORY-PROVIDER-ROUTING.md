# Short-Form Video Factory — Provider Routing Signal

## Purpose
Use specialized video tools as interchangeable production providers rather than hard-coding MONY to one vendor.

## Current capability signals
- AutoShorts.ai: faceless-series generation, scheduling and auto-posting to TikTok, YouTube and Instagram.
- Revid.ai: viral-video discovery, script/generation/editing, publishing, automation, API, MCP and CLI; supports multiple workflow types.
- Vizard: AI clipping, speaker-aware vertical reframing, captions, B-roll, translation, templates and direct publishing.
- OpusClip / Klap / Munch / Vsub: candidate providers for clipping, repurposing, captions or short-form production; verify current API, licensing, export and automation capabilities before production routing.

## MONY routing contract
input → source rights check → content/product understanding → hook candidates → provider capability lookup → generation/repurpose → artifact validation → platform formatting → publish/schedule → outcome telemetry → learn

## Provider selection criteria
- required mode: faceless generation, long-to-short clipping, product ad, avatar, captions, restoration, etc.
- API/MCP/automation availability
- export quality and watermark status
- commercial-use/license constraints
- language support
- cost per accepted artifact
- latency
- deterministic/repeatable controls
- publishing integrations
- failure rate and fallback availability

## Rule
Do not choose a provider because it is popular. Route by verified capability and measured economics. Keep at least one alternate path for important production lanes.

## Affiliate/content integrity
- Affiliate disclosures must remain visible where required.
- Do not fabricate product claims, testimonials, reviews, performance numbers or personal experience.
- Preserve product identity and protected attributes when generating product creatives.
- Track source URL, product ID, affiliate attribution and published artifact ID separately.

## Verification
A provider is production-ready only after a real artifact passes: hook clarity, factual/product integrity, audio, captions, aspect ratio, duration, export, licensing, and publishing checks.
